# aiseed.dev 記事エディタ

WordPress の管理画面に似せた、記事編集専用のデスクトップアプリ(Flet 0.86)。
シリーズ単位 AsciiDoc(`articles/<series>.adoc`)のうち**本文だけ**を編集する。
フロントマターや記事の区切りには触れないので、構造を壊す心配がない
(保存時に必ず再パース検証し、壊れる編集は拒否して元に戻す)。

## 起動

```bash
cd ~/dev/website-adoc
./.venv/bin/python apps/site-editor/main.py
```

## 使い方(WordPress と同じ感覚)

1. **左サイドバー**でシリーズを選ぶ(投稿タイプの一覧に相当)
2. **記事一覧**でタイトルをクリック(検索ボックスで絞り込み可)
3. **編集画面**で「日本語」「English」タブを切り替えて本文を編集
4. **「更新」**を押すと保存 → 数秒でビルドされ、開いているプレビューは
   自動でリロードされる
5. **「プレビュー」**でその記事の実際のページをブラウザで開く

起動時にプレビューサーバー(ライブリロード付き `tools/serve.py`)が
自動で立ち上がる(既に動いていればそれを使う。ポートは環境変数
`AISEED_PREVIEW_PORT`、既定 8000)。

本文は AsciiDoc 形式: 見出し `==`、強調 `*太字*`/`_斜体_`、リスト `*`/`.`、
引用 `____`、表 `|===`、Mermaid は ```` ```mermaid ```` フェンス。

## テスト

```bash
./.venv/bin/python -m pytest apps/site-editor/tests/ -q
```
