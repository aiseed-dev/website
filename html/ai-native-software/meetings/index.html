Teams の会議も、Calendly の予約も、講座のウェビナーも ── 自分のドメインで

2026.07.11 🌐 EN

会議も予約も、汎用の機能だ。Teams の打ち合わせ、Calendly の日程調整、 Microsoft Bookings の講座予約 ── どれも、すでに OSS で共有されている。前章でメールを自分の側に戻した。ここでは三つを立て、2-02 で AI に渡した一台と、自分のドメインの上に置く。

  • ビデオ会議 ── Jitsi Meet(Teams・Zoom の代わり)
  • 予約 ── Cal.com(Calendly・Bookings の代わり)
  • 講座・ウェビナー ── BigBlueButton(大人数の授業向け)

会議は Jitsi Meet で立てる

少人数から中人数の会議は Jitsi Meet である。参加者はブラウザだけでよい。アプリのインストールも、アカウントも要らない。リンクを送れば会議が始まる。

# 公式の compose 一式を使う
git clone https://github.com/jitsi/docker-jitsi-meet
cd docker-jitsi-meet && cp env.example .env && ./gen-passwords.sh
docker compose up -d        # web・prosody・jicofo・jvb が立つ

meet.example.com を、自分のロゴと自分のドメインで配れる。録画もチャットも画面共有も、標準で揃う。

大人数(数百人)の会議は、映像中継(JVB)を増設して捌く。これは「立てる」より「足す」── 規模に応じてサーバを並べる作業だ。

講座は BigBlueButton で開く

セミナーや授業のように、ホワイトボード・挙手・ブレイクアウト・出席が要る場面は BigBlueButton である。教育向けに作られたウェビナー基盤で、2-03 で触れた「講座」のための道具だ。

BigBlueButton は専用のインストーラを持ち、Jitsi より重い。*日常会議は Jitsi、講座は BigBlueButton*、と用途で分けて立てる。

予約は Cal.com に乗せる

日程調整・講座予約は Cal.com である。Calendly と Microsoft Bookings の置き換えで、データは 2-03 の PostgreSQL に乗る。

# compose.yaml ── 予約を 2-03 の DB に乗せて立てる
services:
  booking:
    image: calcom/cal.com:latest
    environment:
      DATABASE_URL: postgres://postgres:change-me@db:5432/calcom
      NEXT_PUBLIC_WEBAPP_URL: https://book.example.com
    restart: always

予約が入れば、2-07 のメールで確認と前日リマインドが飛び、Jitsi の会議リンクが自動で添えられる。土台(DB)・門番(認証)・メールの上に、予約がそのまま乗る。先に据えたものが、ここで効いてくる。

カレンダーは CalDAV で同期し、門番の内側に置く

予定の同期は CalDAV である。軽量な Radicale を一つ立てれば、Thunderbird やスマホの標準カレンダーとつながる。Cal.com と各アプリは、2-04 の門番の内側、リバースプロキシの先に置く。

meet.example.com { reverse_proxy jitsi-web:80 }
book.example.com { reverse_proxy booking:3000 }

移行は、未来の予定だけでいい

Teams や Google カレンダーからの移行に、プロジェクトは要らない。会議のリンクは使い捨てで、移すものが無い。カレンダーは未来の予定だけを .ics で書き出して Radicale に読み込む。一度きりの操作だ。過去の録画やチャットに残す価値のあるものは、2-11 の情報の整備で棚卸しして、ファイルとして 2-06 の置き場に入れる。

確かめ方

この章は、次の五つができていれば済みだ。

  1. 別の PC のブラウザから meet.example.com の会議に入れる。アプリもアカウントも要らない
  2. 二人以上で入って、映像・音声・画面共有が通る
  3. book.example.com で予約を入れると、確認のメールが届き、Jitsi のリンクが付いている
  4. Thunderbird かスマホの標準カレンダーが、CalDAV でその予定を表示する
  5. 講座を立てたなら、BigBlueButton でホワイトボードと挙手が動く
curl -sI https://meet.example.com | head -1   # 会議の頁が返る
curl -sI https://book.example.com | head -1   # 予約の頁が返る

人が持つ物

人が渡す値

  • 会議と予約のドメイン名(meet.example.com・book.example.com)
  • その名前を指す DNS の設定
  • Cal.com がつなぐ DB の接続先とパスワード
  • 予約の受付時間と、一枠の長さ
  • 確認メールの差出人アドレス(2-07 のメール)
  • 移す未来の予定の .ics

AI が「やる前に言う」操作

  • DNS のレコードを変える
  • 予約の確認メールを、外のアドレスへ実際に送る
  • 既に入っている予約のデータを消す
  • 会議の録画を、外から見える場所に置く

確かめた版と日付

  • Jitsi Meet(docker-jitsi-meet の compose 一式)、BigBlueButton、Cal.com(calcom/cal.com:latest)、Radicale、Caddy、PostgreSQL
  • 手順を書いたのは 2026-07-11
  • 版が上がっていたら、AI に公式の手順を確かめさせてから進める
