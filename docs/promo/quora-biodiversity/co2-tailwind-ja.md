**Q. 気候変動は農業には悪いことばかりなのでしょうか?**

先に、はっきりさせておきます。気候変動は、干ばつ・豪雨・熱波・受粉昆虫の減少という形で、農業に深刻な打撃を与えています。ここはまったく揺らぎません。

そのうえで、あまり語られない一面があります。**大気中のCO2濃度の上昇そのものは、ある条件のもとでは、農業にとって追い風になりうる**、という話です。

理由は単純で、**植物にとってCO2は食料だから**です。植物は光合成でCO2から炭水化物を作ります。そして健全な植物は、その炭水化物の2〜6割を、糖の形で根から土の中の微生物に渡します。菌根菌はそのお返しに、土からリンや窒素や水をかき集めて植物に届ける。CO2が増える → 光合成が増える → 微生物へ渡る炭素が増える → 土が肥える、という循環です。

ただし、これには**大きな条件が付きます**。この循環は、土の中の微生物ネットワークが生きている場合にだけ働く。化学肥料を多投した畑では、植物は「肥料が目の前にあるなら微生物と組む必要はない」とばかりに共生を止めてしまう。すると、増えたCO2を土に流し込む配管そのものが、詰まっています。

だから、これは「CO2を出してよい」という話ではまったくありません。逆です。**土壌の生物多様性が生きていて初めて、大気の変化を土の肥沃さに変えられる。** このスペースの順序 ──「生物多様性が基盤、食料がその上、気候変動は全体を揺さぶる条件」── が、まさにここに現れます。同じCO2上昇が、健全な土では追い風になり、死んだ土では素通りする。分かれ目は、土の中の生きものです。
