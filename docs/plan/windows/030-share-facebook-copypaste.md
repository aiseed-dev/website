【注意喚起】Microsoft アカウント、盗まれたら戻ってこないかもしれません。

いま、こんな被害が続いています。

ある朝、突然ログインできない。
パスワードを勝手に変えられている。
回復用のメールアドレスまで、他人のものに書き換えられている。
「私のアカウントです」と証拠を出しても ── 戻ってこない。

こういう報告が、Microsoft 自身の公式サポート掲示板にいくつも上がっています。

原因は単純で、一つの ID に何もかも束ねられているからです。
Windows も、メールも、ファイルも、買ったソフトも、
そして「乗っ取られたときに助けを求める窓口」まで、全部同じ鍵の内側。
家の鍵を盗まれたら、その家の中に合鍵の再発行窓口がある ──
泥棒が中から鍵をかけたら、もう二度と入れない。いま起きているのは、そういうことです。

しかも最近の Windows は、ファイルを見る画面にまで広告を出すようになりました。
いちばん信頼している画面が、そのままウイルスの入口になりえます。
広告が入口、パスワード窃取が出口 ── 一本の線でつながっています。

これは特定の会社を憎む話ではなく、「一社にすべてを預ける」形そのものの危うさの話です。
今日からできる守りと、根本の解決(手元の Windows を、そのまま無料の OS「Debian」に入れ替える)まで、専門用語なしで書きました。
