## 本文

こんにちは。aiseed.dev です。

今日は、緊急でお伝えしたいことがあります。**Microsoft アカウントの乗っ取り被害**が、いま続発しています。

手口はこうです。

- ある朝、ログインできなくなる
- パスワードを勝手に変えられている
- あわてて再設定しようとすると、登録してあったメールアドレスや電話番号まで、他人のものに書き換えられている
- Microsoft に「これは私のアカウントだ」と証拠を出しても ── **戻ってこない**

自動の復旧手続きは通らず、人間の担当者にもなかなかたどり着けない。メール・写真・連絡先・買ったソフトが、鍵を持った他人のものになる。こうした報告が、Microsoft 自身の公式サポート掲示板にいくつも上がっています。

■ なぜ、こんなことになるのか

これは「うっかり変なリンクを踏んだ人」だけの問題ではありません。**一つの ID に、何もかもが束ねられている**という仕組みそのものが原因です。

Windows のログインも、メールも、ファイルも、買い物も、そして「乗っ取られたときに助けを求める窓口」まで、全部が同じ一つの鍵。だから鍵を一本盗まれると、生活まるごと持っていかれる。しかも助けを求める窓口が、その同じ鍵の内側にある ── 家の中に合鍵の再発行窓口があるようなものです。

■ しかも、広告が入口になる

最近の Windows は、ファイルを見る画面(エクスプローラー)にまで広告を出します。これは「うっとうしい」で済みません。**いちばん信頼している画面に、よそから来たものを流し込む通り道**ができた、ということ。その通り道には、ウイルスも流し込めます。広告が入口、パスワード窃取が出口 ── 一本の線です。

■ いま、何をすればいいか

記事では、今日すぐできる応急処置(多要素認証、回復用連絡先の確認 ほか)から、根本の解決まで、専門用語なしで書きました。根本の解決とは、**いま使っている Windows パソコンを、そのまま無料の OS「Debian」に入れ替える**こと。新しいパソコンは要りません。広告も、勝手な AI も、一社に握られたアカウントもない、自分の作業場所になります。
