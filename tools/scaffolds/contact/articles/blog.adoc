= ようこそ

このサイトには**サーバーもデータベースもありません**。記事はこのフォルダの
中のファイル、履歴は git、公開は静的HTMLです。壊れる部品が無いので、
更新も脆弱性対応も要りません。

== 書くには

三通りあります。好きなものをどうぞ。

. **aiseed-builder**(WordPress風の管理画面)—— いちばん簡単
. エディタで `articles/*.adoc` を直接開く
. 開発サーバーを起動して、保存するたびに反映を見る

----
python3 tools/serve.py     # 保存 → 自動ビルド → ブラウザが自動更新
----

== 構造

|===
| 場所 | 中身

| `articles/*.adoc` | 記事(シリーズごとに1ファイル、日英入り)
| `articles/assets/` | 画像・PDF
| `html/` | 公開されるHTML(ビルドで作られる)
| `tools/` | ビルドの仕組み
| `site.json` | サイトの設定
|===
endif::[]
ifdef::lang-en[]
= Welcome

This site has **no server and no database**. Articles are files in this
folder, history is git, and publishing is static HTML. Nothing here can
break, so there is nothing to patch.

== Writing

Three ways — pick one:

. **aiseed-builder** (a WordPress-like admin) — the easiest
. Open `articles/*.adoc` in your editor
. Run the dev server and watch changes appear as you save

----
python3 tools/serve.py     # save → rebuild → the browser refreshes itself
----

== Layout

|===
| Path | What it holds

| `articles/*.adoc` | Articles (one file per series, both languages)
| `articles/assets/` | Images and PDFs
| `html/` | The published HTML (produced by the build)
| `tools/` | The build engine
| `site.json` | Site settings
|===
endif::[]

= お問い合わせ

ご質問・ご依頼は、以下のフォームからお願いします。 +
担当より、折り返しご連絡します。

// ↓ フォームの定義。この JSON だけを触ればフォームが変わります。
//   編集は tools/form-builder/form-builder.html をブラウザで開くのが楽
//   (項目を並べて JSON を書き出す道具。表計算で作るなら form_xlsx.py)。
//   action と sitekey は、cf-publish で受信箱を立てたときの値に置き換えます。
[.form]
{
  "action": "https://<WORKER>.workers.dev/submit",
  "sitekey": "<TurnstileのSITEKEY>",
  "confirm": true,
  "fields": [
    {"name":"your-name",    "label":"お名前",           "type":"text",     "required":true, "placeholder":"例)山田 太郎"},
    {"name":"your-email",   "label":"メールアドレス",    "type":"email",    "required":true},
    {"name":"category",     "label":"種別",             "type":"select",   "required":true, "options":["ご質問","ご依頼","その他"]},
    {"name":"your-message", "label":"お問い合わせ内容",  "type":"textarea", "required":true}
  ]
}

お預かりした個人情報は、お問い合わせへの回答のみに使用します。

送信されたものは、aiseed-builder の「フォーム受信箱」で受け取ります
(サーバーは立てません。Cloudflare の受信箱に溜まったものを、手元に
取りに行く形です)。
endif::[]
