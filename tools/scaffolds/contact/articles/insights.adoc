== AsciiDoc の基本

見出しは `==`、*太字* は `*` で囲み、_斜体_ は `_` で囲みます。

* 箇条書きは `*`
* 入れ子は `**`

番号付きは `.` で始めます。

引用は `____` で囲みます。

= First Article

This article lives inside `articles/insights.adoc`. **One series is one file**,

== How to write

The block fenced by `---` is the frontmatter. Keys shared by both languages
are bare; keys that differ are written as `title.ja` / `title.en`. The body
goes inside `ifdef::lang-ja[]` … `endif::[]`.

Links to the previous/next article are derived from document order, so you
never write them.

== AsciiDoc basics

Headings use `==`, *bold* uses `*`, and _italic_ uses `_`.

* Bullets use `*`
* Nesting uses `**`

Numbered lists start with `.`.

[quote]
____
Quotes are fenced with `____`.
____

'''

To build:

----
python3 tools/build_article.py --all   # everything
python3 tools/serve.py                 # dev server (auto-reload on save)
----
endif::[]
